#  Java 11 Basics

### Statements Structure
- Programs are made up of statements
- Statements end with a semicolon

### Comments
- A string of text that is ignored by the compiler
- Used to add human readable notes
- Used to hide source code without deleting it

#### Types of Comments
- `// code here` - Line comment, text ignored until the end of the current line
- `/* code here */` - Block comment, everything between is ignored
- `//* code here */` - Javadoc comment, everything between is ignored, used to generate documentation

### Packages
- Packages provide organization
- Follow standard naming convention
- Affect source code structure

#### Package Naming Conventions
- All lowercase
- Use reverse domain name notation to assure global uniqueness
- Add further qualifiers to assure uniqueness with a company or group
