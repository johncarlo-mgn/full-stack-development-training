# Java Core

### keywords
- are reserve words, cannot be used as a variable name, classname or method name.

### Integral Literals
- whole numbers (byte, long, short, int)

### Comments
- we can use @ (annotations) in comments

### Types of variable declarations
- local (automatic) variable - owned by the function, when the function ends local variables end (revive when called)
- instance variable - owned by the object 
- class variable - owned by the class, one value in all object instance

### Variable name
- starts with letter, underscore or $, not with numbers.

### Search Java Docs
- java System api (looking for System api)

### Local Variables
- 0 is not the default value, unlike instance and class variables

### Underscore for readability
` int i = 125_550 `

### Type Casting 
- implicit = automatic (widening or upcasting)
- explicit = manual (narrowing or downcasting)

### Naming Conventions
- Class names = use Pascal Case (eg. NumberOne)
- Variable and Method names = use Camel Case (eg. numberOne)

### When to use double
- use when working in financial application project

### Unicode vs ASCII
- ASCII = American Standard Code for Information Interchange
- Unicode = All Human known symbols

### Boolean naming
- use question = `isOct30Payday = true;`

### instanceof Operator
- use for introspection

### Every class has Object as parent class
- means every class extends Object

### Shorthand Operator
`n += 10; // means n = n + 10;`
