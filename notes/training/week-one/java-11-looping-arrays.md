### While Loop
- continue running as long as the condition is true
```
while(condition){
    statement;
}
```

<br>

### Do-while 
- condition is checked at the end of the loop
- continue running as long as the condition is true
- always rund at least once

```
do{
    statement;
} while (condition);
```
<br>

### For Loop
- condition checked at loop start

```
for(initialize; condition; update){
    statement;
}
```
